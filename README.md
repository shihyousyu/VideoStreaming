# Video Streaming Code

This repository contains 10 development versions of a Python RTSP/RTP MJPEG video streaming project.

The project started from the course-provided `origin` template. Earlier versions explored extra media-player features, while `v3.0` was rebuilt to match the assignment requirements more directly.

## Main Versions

- Assignment version: [v3.0 README](./v3.0/README.md)
- Personal work version: [v2.4 README](./v2.4/README.md)
- Full version history: [CHANGELOG.md](./CHANGELOG.md)

## Version Overview

| Version | Purpose |
| --- | --- |
| `v1.0` | Completed the basic course skeleton. |
| `v2.0` | Added fast/slow playback and forward/backward seek. |
| `v2.0.1` | Improved cache handling and paused seek display. |
| `v2.1` | Added progress bar and time display. |
| `v2.1.1` | Fixed missing-file handling during SETUP. |
| `v2.1.2` | Refactored client request/button logic. |
| `v2.2` | Added GUI connection settings and file picker. |
| `v2.3` | Reorganized the GUI layout. |
| `v2.4` | Added server-side file browsing for cross-machine streaming. |
| `v3.0` | Rebuilt from `origin` for the assignment, including required work and optional exercises. |

## Notes

- Use `v3.0` for the assignment submission.
